# CONCEITS.md — one idea per card, approved before any prose exists

Work Order v3 §2. Each line names the specific concrete situation the card is
built around — the thing we point at, not the traditional definition. Domain
and opening move are assigned here and lint-checkable. Constraints satisfied
below — no domain over six uses, no card sharing a domain with its deck-order
neighbour, opening moves distributed 20 / 20 / 19 / 19.

Marking key for review — leave each line as **accept** or mark **recast**
(one short note on why). No prose gets written until this list is approved.
